# BUG REPORT: Console Errors on Page Refresh

## Tested Website
https://the-internet.herokuapp.com/login

## Environment
- Browser: Google Chrome
- Tool: Chrome DevTools (Console)
- OS: Windows

## Precondition
User is on the login page

## Steps to Reproduce
1. Open login page
2. Open Chrome DevTools (F12)
3. Go to Console tab
4. Refresh the page multiple times

## Actual Result
Console shows red error messages during page refresh.

## Expected Result
Console should not show errors that impact page functionality or user experience.

## Notes
Need to verify whether these console errors affect application behavior or are related to non-critical resource loading.

## Severity
Low / Needs further investigation
