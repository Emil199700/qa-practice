# Test Case ID: TC_024

## Title
Add Product to Cart

## Tested Website
https://automationexercise.com/

## Module
Cart

## Preconditions
User is on the home page

## Test Steps
1. Select a product
2. Click the "Add to Cart" button
3. Open the cart page

## Expected Result
The selected product should be successfully added to the cart and displayed in both the cart icon and cart page.
